# tech-writing-style

Writing norms applied to Japanese technical documents: architecture decision records, wiki pages, issues, pull request descriptions, article drafts, and book chapters.

The norms cover phrasing that costs the reader an extra step, consistent notation, the reader level to write for, structuring with tables and lists, how to lay out a procedure, what a heading has to carry, and where a link belongs.

The skill body is written in Japanese, as are the documents it governs.
